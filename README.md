# 杭州大礼包计算器

一个纯前端、移动端优先的大礼包金额估算工具。用户输入前 12 个月平均工资、起算日期和结算日期，即可估算标准、加码与双倍三档礼包。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 测试与构建

```bash
pnpm test
pnpm build
```

## 说明

- 所有数据只在浏览器本地计算，不上传、不保存。
- 页面结果仅为数学估算，不构成法律意见。
- 默认采用杭州市统计局公布的 2025 年私营单位就业人员年平均工资 95545 元，对应三倍月上限 23886.25 元；其他单位或年度可在高级设置中修改。
- 默认杭州市区最低月工资为 2660 元，标注适用日期为 2026-01-01。
- N+1 中的“+1”依据《劳动合同法实施条例》第二十条，按结算前一个月工资标准计算；未填写时仅以十二个月平均工资暂估并显示提醒。

## 法律来源

- 《中华人民共和国劳动法》第二十八条
- 《中华人民共和国劳动合同法》第四十、四十六、四十七、四十八、八十七、九十七条
- 《中华人民共和国劳动合同法实施条例》第二十、二十七条
- 杭州市人社局相关计算标准说明
- 杭州市区 2026 年最低工资通知
