# 杭州离职大礼包计算器

一个纯前端、移动端优先的经济补偿/赔偿金额估算工具。用户输入前 12 个月平均工资、入职日期和离职日期，即可估算 N、N+1 与 2N。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 测试与构建

```bash
pnpm test
pnpm build
```

## 说明

- 所有数据只在浏览器本地计算，不上传、不保存。
- 页面结果仅为数学估算，不构成法律意见。
- 上年度杭州职工月平均工资需由用户根据适用年度和官方口径填写。
- 默认杭州市区最低月工资为 2660 元，标注适用日期为 2026-01-01。

## 法律来源

- 《中华人民共和国劳动法》第二十八条
- 《中华人民共和国劳动合同法》第四十、四十六、四十七、四十八、八十七、九十七条
- 《中华人民共和国劳动合同法实施条例》第二十、二十七条
- 杭州市人社局经济补偿标准说明
- 杭州市区 2026 年最低工资通知
